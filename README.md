# Tippy-Toes
A precision app to help pet owners track and maintain schedules for trimming their pets' nails.

## 🔗 Live Application
Check out the fully functional live deployment here: https://tippytoesapp.vercel.app/

## ✨ Key Features
- **Polydactyl Support:** Dynamically add extra toes and tracking slots for animals born with extra claws.
- **Amputee & Paw Difference Layouts:** Fully adjustable paw mapping allows users to remove paw slots or track care for unique paw structures.
- **Micro-Counting & Multi-Sitting Tracking:** Tracks each nail independently, allowing owners to pause and resume trims across multiple sittings easily.
- **Adjustable Trimming Countdowns:** Custom reminders handle the different growth cycles for front and back claws natively.
